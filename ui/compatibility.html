把 API 信息导入 Magpie

  1. 打开“插件 → 已安装”，找到“API 导入”，点击“登录”。也可在终端运行 magpie plugin login api-import。
  2. Magpie 会打开本机导入页。在那里粘贴文字、JSON 或截图，也可选择图片。
  3. 点击“识别并验证”。缺少模型时会获取列表供你选择，再验证；截图识别的 Key 需要逐字核对。
  4. 验证通过后点击“确认添加”，返回 Magpie 查看登录结果。

支持 New API 复制的连接 JSON：根地址会补上 /v1。配置保存为“API 导入”供应商的账号。模型列表会显示你的名称、原模型和 API 域名；不同地址或 Key 的同名模型分别显示。

只提供本次验证通过的模型。再次登录可添加其他 API 或模型。验证会真实调用上游接口，可能产生少量费用。

此说明页不读取剪贴板。导入由你主动发起，不会在原生“自定义供应商”表单中自动运行。不支持远程服务器代替本机浏览器导入。
