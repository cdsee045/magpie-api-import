# 0.3.0 验收记录

当前按用户要求采用官方登录流程。原始“新建自定义供应商自动读剪贴板、原生配置追加”已调整为“主动登录、本机粘贴/选图、保存插件账号”；两种流程不能混称。

运行 `npm run check` 验证模块和两套浏览器回归；`npm run test:magpie` 验证本机官方运行时。原生桌面窗口人工交互、真实供应商费用/额度、工具调用、远程浏览器和更早版本未覆盖。

0.2.5 的验收只证明条数及人工修正后的验证流程，没有解决 OCR 准确性；第二条 Key 的手抄对照值还存在 i/j 错误，先前 401 不能作为原图凭证无效的结论。0.3.0 已纠正该对照值，原图仅在本机内存处理，真实编码和原图未加入仓库。

在用户明确授权的总额度内，新流程经 Bun 正式导入会话直接上传原图、不手改 Key/地址/模型：三条 Key 的模型查询均返回 200。第二条首次生成验证使用服务端实际返回的模型 ID，单次、1 token 请求返回 200，并出现确认窗口。第一、第三条沿用此前已完成的最小生成验收，不重复收费。未写正式账号，未把当次可用性视为长期保证。该范围包含 Bun 导入会话和浏览器流程，不等于已覆盖真实供应商在完整官方网关中的流式/工具调用；官方 Magpie 宿主仍用虚构凭证做隔离回归。
