# 0.2.2 验收记录

当前按用户要求采用官方登录流程。原始“新建自定义供应商自动读剪贴板、原生配置追加”已调整为“主动登录、本机粘贴/选图、保存插件账号”；两种流程不能混称。

| 要求 | 验证 | 结果 |
| --- | --- | --- |
| 官方加载和登录入口 | 安装的 Magpie 0.1.4248 及其原始 Bun 宿主 | 通过，无需补丁 |
| 官方账号保存、重载 | 实际 authorize/callback，再由官方 CLI 重载 | 通过，虚构 Key |
| 同配置/模型更新原账号 | 实际宿主连续导入两次 | 通过，只保留一个账号 |
| 不同服务商同名模型隔离 | official.test.ts | 不同 URL/Key 对应不同内部 ID，上游保留原 ID |
| 只提供已验证模型 | 官方宿主模型和元数据断言 | 通过，未注册其他模型 |
| HTTP 转发钩子 | 实际宿主 fetch + 本机 HTTP | 通过，未覆盖完整代理网关和所有协议转换 |
| 取消不保存、其他账号保留 | 实际官方 auth 存储比较 | 通过，隔离数据 |
| 主动输入，无自动剪贴板调用 | 首次无验证，粘贴/上传后处理 | 通过 |
| 文字、JSON、明确 Base64、多 Key | parser/controller/正式页面 | 通过，一轮一条 |
| Base64 同行/换行、空行、反引号、省略填充 | parser 与正式页回归 | 通过，仅明确标注才解码，畸形编码不猜测 |
| 一个 URL 多条普通/Base64 Key，不同 URL 分组 | parser、正式页、实际官方宿主 | 保留名称和共享地址；选择前无请求，只验证并保存选中的 Key |
| New API 根地址补 /v1，显式路径保持不变 | parser 回归 | 通过，只有明确格式才转换 |
| 未指定模型时自动获取、下拉选择后验证 | controller/正式页真实 HTTP | 通过，获取列表无生成调用，不猜测模型 |
| 模型列表 404 和生成 404 分别提示 | validator 回归 | 通过，错误不回显原始内容 |
| 本地 OCR、截图 Key 人工核对 | 真实 Tesseract 合成截图、正式页上传 | 通过，未量化真实截图准确率 |
| 最小真实调用、列表不算验证 | validator/HTTP 集成 | 通过，仅本机 API stand-in |
| 一次确认、私有凭证、编辑失效 | host/controller/official | 通过 |
| 关页/隐藏/取消丢弃迟到结果 | 浏览器/生命周期测试 | 通过 |
| 来源检查、脱敏、不跟随重定向 | official/validator/浏览器 | 通过 |
| 320/375/736/1100 明暗主题 | 正式页 Playwright | 通过，artifacts/official-ui |
| 匿名 GitHub 下载、安装包 OCR | test:github-install | 从 main 下载后运行正式会话 OCR |
| 历史演示和 Go 库 | 原 Demo/浏览器/Go | 保留回归，不是当前正式入口 |

运行 `npm run check` 验证模块和两套浏览器回归；`npm run test:magpie` 验证本机官方运行时。原生桌面窗口人工交互、真实供应商费用/额度、工具调用、远程浏览器和更早版本未覆盖。
