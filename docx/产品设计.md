# Magpie API 自动配置插件产品设计

面向 Magpie 用户的 API 配置导入插件。用户复制 API 信息后，进入“供应商 → 自定义供应商”，插件自动识别并验证；验证通过后，用户确认一次即可添加，减少手动填写和配置错误。

## 使用流程

复制 API 文字或截图 → 打开自定义供应商页面 → 自动识别 → 验证接口可用 → 展示配置并询问是否添加 → 用户确认后保存。

其他页面不读取、不检测、不提示。离开自定义供应商页面后，停止后续检测并丢弃迟到的提示结果。

## 主要功能

| 功能 | 主要内容 |
| --- | --- |
| 指定页面触发 | 仅进入“供应商 → 自定义供应商”时读取剪贴板，提供自动识别开关和手动重新检测入口。 |
| 多种输入识别 | 支持普通文本、截图和包含 url、key 的 JSON；对明确标注为 Base64 的 Key 进行解码。 |
| 配置提取与补全 | 提取名称、API 地址、Key、协议和模型；规范化地址，缺失或模糊字段提示补全，不猜测密钥。 |
| 可用性验证 | 按实际协议，对至少一个模型完成最小真实调用后才提示添加；仅获取模型列表不算验证通过。验证可能产生少量费用。 |
| 一次确认添加 | 确认框展示域名、脱敏 Key、协议和验证通过的模型；确认后保存配置，保留现有默认选择。 |
| 多 Key 选择 | 一份内容有多个 Key 时，在当前页面列出候选；首版每次选择一条验证并导入。 |
| 去重与异常处理 | 同一配置避免重复检测和提示；已有相同配置提示已存在。检测失败仅显示页内原因和重试入口，不弹添加确认框。 |
| 敏感信息保护 | 识别优先在本地完成；Key 脱敏展示，原始剪贴板、截图和 Key 不写入日志或 Git。 |

## MVP 范围

- 首版面向 Windows 上的 Magpie，以插件形式安装和使用。

- 优先支持常见 Chat Completions 兼容接口，以及已提供的文本、JSON、截图和 Base64 Key 输入形式。

- 验证结果与具体地址、Key、协议和模型绑定；修改关键字段后重新验证，其他模型保留为未验证。

- 后续再扩展其他协议、批量导入和更多输入格式；API 余额查询、自动切换供应商及跨软件配置不纳入首版。

## 实现前提

需先验证 Magpie 当前版本是否开放新建自定义供应商表单的挂载、剪贴板读取和配置保存能力。现有公开文档中的 provider 插槽对应已保存供应商的编辑器；如扩展接口不足，需要宿主补充支持，才能实现指定页面内的一次确认流程。[Magpie 插件文档](https://usemagpie.ai/docs/plugins)

## 验收重点

仅指定页面触发；实际调用成功才询问添加；一次确认完成保存；失败或取消不新增配置；重复内容不反复打扰；离开页面不弹窗；原有配置不受影响。
